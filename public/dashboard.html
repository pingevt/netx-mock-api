POST-only demo surface

NetX Mock API, but showable in a browser.

This dashboard wraps the JSON-RPC endpoint in a simple workflow: pick a method, send a POST request, inspect the response, and browse live thumbnails from the same mock data the Drupal module uses.

What it proves
Real POST calls
Every action on this page goes through the JSON-RPC endpoint with the same request shape the Drupal module uses.
Media output
Thumbnails
Results can render live images from the unauthenticated file routes, so the demo feels visual instead of abstract.
Best for
Coworker walkthroughs
Open one URL, click one button, and show the full flow from folder browsing to asset preview.
